# QA Automation Technical Assessment — Trading Platform Requirements

## Description

Develop automated tests for a trading platform to demonstrate test design, programming, validation, and code quality using Python and JavaScript/TypeScript, including Playwright.

Test Duration: 2 Days

## Functional Scope

1. Place Buy/Sell Market Orders with Stop Loss and Take Profit.
2. Place Buy/Sell Market Orders with One-Click Trading enabled.
3. Place and manage Pending Orders with supported order types and expiry options.
4. View, modify, partially close, and close open positions.
5. Perform bulk close or delete operations on supported orders.
6. View trading transactions, order notifications, and order history.
7. Verify order details and transaction status across relevant trading records.

## Assumptions

1. Register and use a demo trading account with virtual funds.
   - Demo registration: https://www.aquariux.com/solutions/trader/
2. Select suitable trading instruments and test data based on the demo environment.
3. Document any market closure, environment limitations, or assumptions.

If the market is closed, analyse the requirements based on own understanding and develop the code.

## Important Note

Use git to track progress. Perform an "initial commit" at the start of the test and an "end commit" at the end. Provide the GitHub repository URL.
